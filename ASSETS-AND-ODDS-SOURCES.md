# Источники вероятностей и изображений

## Шансы открытий

Модель использует как публичный базовый ориентир опубликованные для CS2 оружейных кейсов вероятности групп редкости: базовая/Mil-Spec — 79,92%, Restricted — 15,98%, Classified — 3,2%, Covert — 0,64%, Exceedingly Rare — 0,26%. Публичный обзор, ссылающийся на публикацию Valve: https://csgoskins.gg/blog/csgo-case-odds-the-official-numbers-published-by-valve

Consumer/Industrial объединяются с базовой группой; отсутствующие в конкретном пользовательском пуле группы нормируются. Поверх базовой rarity-модели публичная ценовая калибровка — экспоненциальное взвешивание стоимости предметов — настраивает каждый кейс на целевую среднюю отдачу 85% цены открытия. Это значение ожидаемой стоимости при большом количестве независимых открытий, а не выигрыш или возврат отдельного игрока. Калибровка применяется в обе стороны, чтобы исправить как чрезмерно щедрые, так и необоснованно низкие базовые пулы.

Итоговые групповые и индивидуальные шансы рассчитываются одним модулем `lib/case-balance.js`, используются при выдаче дропа и отдаются через `GET /api/case-odds/:id`. Модель не учитывает имя, баланс, прошлые выпадения или серию игрока; массовое открытие не меняет вероятность броска.

## Игровые изображения

В проект локально включены 131 PNG-превью предметов Steam Community Economy CDN размером 256×256. Названия в приложении сопоставлены с точным англоязычным canonical item name; изображения сохранены в `public/skins/000.png`–`130.png` и обслуживаются локально. Исходные права на игровой арт остаются у Valve/Steam.

Для проверки сопоставлений использованы открытые метаданные CS2 API ByMykel: https://github.com/ByMykel/CSGO-API. По README репозитория metadata/API распространяются под MIT; уведомление об источнике включено в `public/skins/ASSET-SOURCE.txt`. Оригинальные PNG от репозитория ByMykel не копировались: они получены непосредственно из Steam Community Economy CDN. Отдельно сохраняется ограничение авторских прав Valve на сами игровые текстуры.

## Источники категорий

Каталог не содержит достоверного поля серии, поэтому «Серия I» сформирована явным списком ID `0–4`; ценовые категории определяются порогами в `public/case-categories.js`. Это категории навигации, а не типы кейсов, приписанные Valve или стороннему сайту.
